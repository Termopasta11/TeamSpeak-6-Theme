# Angel Glass — TeamSpeak 6 Theme

A custom dark glass-inspired theme for TeamSpeak 6.
<img width="1672" height="941" alt="image" src="https://github.com/user-attachments/assets/2fdbcbc6-8f66-4ef2-8d53-e9eb90ad86df" />

## Installation

1. Download and extract the archive.
2. Make sure the folder is named exactly `user.themes.angelglass`.
3. Place your desired background image inside the theme folder and rename it to `background.jpg`.
4. Copy the entire folder to the TeamSpeak extensions directory:

   **Windows**
   ```text
   %appdata%\TeamSpeak\Default\extensions
   ```

   **Linux**
   ```text
   ~/.config/TeamSpeak/Default/extensions
   ```

5. Open TeamSpeak 6.
6. Navigate to **Settings → Appearance**.
7. Enable **User Theme**, refresh the theme list, and select **Angel Glass**.

## Custom Background

You can use your own background image.

Simply replace `background.jpg` inside the theme folder with your preferred image. Make sure the filename remains exactly the same.
